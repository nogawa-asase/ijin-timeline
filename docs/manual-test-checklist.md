# 手動テストチェックリスト

PRDの受け入れ条件(機能要件1〜4)と非機能要件のうち、ユニットテストで確認できない項目をブラウザで確認するための一覧。UIに関わる変更をした作業の最後、`main` へのマージ前、公開後に使う(`docs/development-guidelines.md` の「手動テストのタイミング」)。

## 準備

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

- 開発者ツールのネットワークタブで「キャッシュを無効化」(Disable cache)にチェックを入れ、開発者ツールを開いたまま再読み込みする。`app.js` から読み込まれるモジュールは通常の再読み込みでは更新されず、古いコードのまま動くことがある
- 開発者ツールのコンソールを開いておき、エラーが出ていないことを随時確認する
- スマホ幅の確認は、開発者ツールのレスポンシブ表示(360px)で行う

## 1. 偉人名の入力と候補選択

- [ ] 画面に人物の入力欄が2つある(PCでは横並び、600px未満では縦並び)
- [ ] 「織田」と入力すると、入力が止まってから約0.3秒後に候補が表示される(開発者ツールのネットワークタブで、1文字ごとには通信していない)
- [ ] 1回の検索の通信が2リクエスト(`wbsearchentities` と `wbgetentities`)である
- [ ] 「織田信長」と入力すると、候補に「織田信長(1534年–1582年)」が出る
- [ ] 候補は最大7件で、人間かつ生年がわかる人物だけが出る(「織田」で名字の項目が出ない)
- [ ] 「織田」と入力すると、織田信長を含む人物の候補が7件出る(名字の項目が検索結果の上位を占めても候補が残る)
- [ ] 候補に「名前(生年–没年)説明」が表示される。存命は `(1970年–)`、没年不明は `(1572年–?)`
- [ ] 候補をマウスでクリック / タップで選択できる
- [ ] 上下キーで候補を移動し、Enterで確定できる。Escで一覧が閉じる
- [ ] 「あいうえおかきくけこ」など該当しない語で「該当する人物が見つかりませんでした」と表示される
- [ ] 開発者ツールでオフラインにして入力すると「データを取得できませんでした。時間をおいて試してください」と表示され、選択済みの人物・タイムラインはそのまま残る
- [ ] オフラインを解除して文字を編集すると、再検索される
- [ ] 選択済みの人物の名前を編集すると選択が解除され、別の人物を選び直せる
- [ ] ×ボタンでクリアでき、タイムライン・結果から消える
- [ ] 候補の各行、×ボタンがスマホ幅で押しやすい(44px以上)

## 2. 生存期間のタイムライン表示

- [ ] 1人も選択していないとき「名前を入力して、比べたい人物を選んでください」と表示される
- [ ] 1人だけ選択すると、その人物の線が表示される(2人目だけ選択した場合はオレンジの線)
- [ ] 横軸に西暦の目盛りとラベルが表示される
- [ ] 1人目は青、2人目はオレンジの線で、入力欄の左の丸と色が一致する
- [ ] 線の上に人物名、線の両端に生年・没年が表示される(入りきらないときは線の下に表示される)
- [ ] 2人の生存期間が重なる区間に黄色の背景が塗られる
- [ ] 360px・768px・1920pxの各幅で、横スクロールなしで全体が見える。幅を変えると描き直される

## 4. データの特殊ケースへの対応

- [ ] 紀元前の年が候補一覧・線の端・結果文章のすべてで「前551年」のように表記される(孔子)
- [ ] 存命の人物は現在の年まで線が引かれ、右端が矢印で「存命」と表示される(羽生善治)
- [ ] 年代・世紀単位の年は線の端が点線になり、「970年代」「11世紀頃」のように表記される(紫式部)
- [ ] 没年不明の人物は線全体が点線になり、右端に「没年不明」と表示される(出雲阿国)
- [ ] 生年が不明と登録されている人物は候補に出ない(卑弥呼)

## 5. 非機能要件

- [ ] マウスを使わず、Tab・上下キー・Enter・Escだけで2人の比較まで操作できる
- [ ] スクリーンリーダー(VoiceOver / NVDA)で、候補の件数・メッセージ・結果の文章が読み上げられる
- [ ] 画面下部に「データ出典: Wikidata」が表示される
- [ ] 開発者ツールのネットワークタブで、Wikidata以外への通信がない。静的ファイルの合計が100KB以内
- [ ] ネットワーク制限「Fast 4G」で、ページを開いてから2秒以内に入力できる。候補は入力停止から1秒以内に出る
