# 要求内容

## 概要

PRD(`docs/product-requirements.md`)のコア機能(P0)4つを実装し、2人の偉人の生存期間をWikidataから取得してタイムラインと文章で比較できる静的Webページを完成させる。

## 背景

永続ドキュメント6点が揃い、実装に入れる状態になった。リポジトリにはまだアプリケーションのコードがなく、テンプレート(TypeScript / npm)由来のファイルだけが残っている。MVPをGitHub Pagesで公開できる状態にすることが今回のゴール。

## 実装対象の機能

### 1. 偉人名の入力と候補選択(PRD 機能1)
- 入力欄2つ。0.3秒のデバウンス後にWikidataを検索し、人間かつ生年のある人物を最大7件表示する
- 候補は「名前(生年–没年)説明」で表示し、マウス・タップ・キーボードで選択できる
- 0件・通信エラーのメッセージ表示、クリア・再編集による変更

### 2. 生存期間のタイムライン表示(PRD 機能2)
- SVGで横軸(西暦)・目盛り・人物ごとの色付きの線・名前・生没年・重なり区間を描く
- 0人のときは案内文、1人のときはその人物の線を表示する
- 360px〜1920pxの画面幅に合わせて縮尺を変える

### 3. 同時代かどうかの結果表示(PRD 機能3)
- 重なり期間・年数・年齢関係、または空白期間を文章で表示する(機能設計書A5の全パターン)

### 4. データの特殊ケースへの対応(PRD 機能4)
- 紀元前の表記、存命(矢印)、あいまいな年(点線・年代/世紀表記)、没年不明、複数値の選択(ランク)

PRDの機能要件1〜4の受け入れ条件をすべて満たすこと。加えて:

## 成功指標

- 入力から比較結果の表示まで、操作に迷わず30秒以内で完了できる
- 静的ファイルの合計が100KB以内

## スコープ外

以下はこのフェーズでは実装しません:

- P1機能(URL共有、3人以上の比較、時代区分・人物詳細)
- P2機能(出来事、提案、画像保存、肖像画)
- GitHub Pagesの公開設定(リポジトリ設定の操作のため、開発者が行う)
- 実機(iPhone / Android)での手動テスト(チェックリストのみ用意する)
