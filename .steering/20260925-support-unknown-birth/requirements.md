# 要求内容

## 概要

生年が不明でも没年がわかる人物(歴史上の卑弥呼など)を候補に出し、タイムラインと比較結果に表示できるようにする。

## 背景

「卑弥呼」と入力しても、歴史上の卑弥呼(Q234451)は候補に出ない。Wikidataでは生年が「不明な値」(`somevalue`)、没年が248年として登録されており、今の仕様では「生年がわかる人物だけを候補にする」ため除外される。

卑弥呼のような古代の人物は、生年が記録に残っていないことが多い。一方で、歴史の学習でよく登場する。教育目的のサービスとして「見つかりません」と表示されるのは避けたい。

今の仕様には、生年だけがわかる「没年不明」への対応(仮の終了年まで点線で描く)がすでにある。これと対になる形で、没年だけがわかる人物にも対応する。

## 実装対象の機能

### 1. 生年不明の人物を候補にする
- 生年が「不明な値」または未登録で、没年(日付の値)がある人物を、候補に含める
- 生年も没年もわからない人物は、これまでどおり候補にしない(描く手がかりがないため)
- 候補一覧では生没年を `(?–248年)` と表記する(没年不明の `(1572年–?)` と対になる形)

### 2. タイムラインに描く
- 没年から50年前を仮の描画開始年とし、線全体を点線で描く(没年不明の「生年+50年」と対になる形)
- 線の左端に「生年不明」、右端に没年を表示する
- 表示範囲・目盛りは、仮の描画開始年を含めて計算する

### 3. 比較結果を表示する
- 生年不明の人物が亡くなった年より後に相手が生まれた場合は、確実に同じ時代ではないため、「重なりなし」の文章を表示する
  - 例: 卑弥呼(?–248)と織田信長(1534–1582) → 「卑弥呼が亡くなってから約1286年後に、織田信長が生まれました」
- 相手が、生年不明の人物の没年より120年以上前に亡くなっている場合も、同じ時代ではないと判定する。人の寿命は長くても120年程度のため(存命の判定と同じ目安)。空白の年数は計算できないため、2人の没年の差を示す
  - 例: 卑弥呼(?–248)と孔子(前551–前479) → 「孔子が亡くなってから約726年後に卑弥呼が亡くなっており、同じ時代ではありません(卑弥呼の生年は不明です)」
- それ以外(相手が生年不明の人物の没年の前後120年以内に生きていた、2人とも生年不明など)は、判定不可とする
  - 文章: 「卑弥呼の生年が不明なため、同じ時代かどうかを判定できません」

## 受け入れ条件

### 生年不明の人物を候補にする
- [ ] 生年が「不明な値」で没年がある人物(卑弥呼)が、Personに変換される(`birth` は `null`)
- [ ] 生年が未登録で没年がある人物も、Personに変換される
- [ ] 生年がわからず、没年もわからない人物は、これまでどおり `null` になる
- [ ] 「卑弥呼」と入力すると、候補に「卑弥呼(?–248年)」が出る。教育上の観点からフィルタリングする職業の同名の人物は出ない

### タイムラインに描く
- [ ] 卑弥呼を選ぶと、198年〜248年の線が点線で描かれ、左端に「生年不明」、右端に「248年」と表示される
- [ ] スクリーンリーダー向けの要約が「卑弥呼 生年不明〜248年」となる

### 比較結果を表示する
- [ ] 卑弥呼と織田信長を比べると「卑弥呼が亡くなってから約1286年後に、織田信長が生まれました」と表示される
- [ ] 卑弥呼と孔子を比べると「孔子が亡くなってから約726年後に卑弥呼が亡くなっており、同じ時代ではありません(卑弥呼の生年は不明です)」と表示される
- [ ] 生年不明の人物の没年の120年前から没年までの間に亡くなった、または生きていた人物と比べると「○○の生年が不明なため、同じ時代かどうかを判定できません」と表示される
- [ ] 生年不明と没年不明の人物を比べると、判定不可になり、両方の理由が文章に含まれる
- [ ] 既存の比較結果(重なりあり・重なりなし・没年不明の判定不可)は変わらない

### 共通
- [ ] `node --test 'tests/**/*.test.js'` がすべて成功する
- [ ] PRD・機能設計書・用語集・手動テストチェックリストに、生年不明の扱いが反映されている

## 成功指標

- 生年が記録に残っていない古代の人物(卑弥呼)を検索・比較できる

## スコープ外

以下はこのフェーズでは実装しません:

- 活動時期(P1317 floruit)など、生年以外のプロパティから生年を推定すること
- 没年不明の人物についても「相手が没年不明の人物の生年より前に亡くなった」場合に重なりなしと判定すること(既存の没年不明の判定は変えない)
- 寿命120年の目安を、没年不明の人物の判定に使うこと
- 相手が生年不明の人物の存命中にいたことが確実な場合(例: 相手の生存期間が生年不明の人物の没年をまたぐ)に「重なりあり」と判定すること。重なりの年数を出せないため、判定不可のままとする
