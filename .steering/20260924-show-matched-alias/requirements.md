# 要求内容

## 概要

候補一覧で、別名(Wikidataのalias)に一致して出てきた人物に「(別名: 豊臣秀綱)」のように一致した別名を表示し、入力した名前と違う人物がなぜ候補に出たのかを分かるようにする。

## 背景

手動テストで「豊臣」と入力したところ、候補に天草四郎が表示され、名前に「豊臣」を含まない人物が出る理由が分からなかった。

調べると、`wbsearchentities` はラベル(正式な名前)だけでなく別名にも一致する。「豊臣」の上位20件では次の人物が別名で一致している。

| 表示される名前 | 一致した別名 |
|---|---|
| 真田信繁 | 豊臣信繁 |
| 宇喜多秀家 | 豊臣秀家 |
| 天草四郎 | 豊臣秀綱 |
| 小早川秀秋 | 豊臣秀俊 |
| 高台院 | 豊臣吉子 |
| 織田信秀 | 豊臣信秀 |

PRDでは別名での検索を想定している(例: 「松平元康」で徳川家康を探す)。このため、別名で一致した候補は除外しない。代わりに一致した理由を示す。

## 実装対象の機能

### 1. 一致した別名の取得
- `wbsearchentities` の応答の `match`(`type` / `text`)から、別名で一致したかどうかと、一致した別名を読み取る
- 通信回数(2回)・取得件数(20件)・表示件数(最大7件)・候補の順番は変えない

### 2. 候補一覧への別名の表示
- 別名で一致した候補は、生没年の後ろに「(別名: {一致した別名})」を表示する
  - 例: `天草四郎(1621年–1638年)(別名: 豊臣秀綱)`
- ラベルで一致した候補は、これまでどおりの表示にする
- 候補を選んだ後の入力欄・タイムライン・結果の文章には別名を表示しない

## 受け入れ条件

### 一致した別名の取得
- [ ] 検索結果の `match.type` が `alias` の候補は、一致した別名(`match.text`)を持つ
- [ ] `match.type` が `label` の候補、`match` がない候補は、別名を持たない
- [ ] 一致した別名が表示名(label)と同じ場合は、別名を持たない(同じ名前を2回表示しないため)
- [ ] `node --test 'tests/**/*.test.js'` がすべて成功する

### 候補一覧への別名の表示
- [ ] 「豊臣」と入力すると、天草四郎の候補に「(別名: 豊臣秀綱)」と表示される
- [ ] 「豊臣」と入力すると、豊臣秀吉の候補には別名が表示されない
- [ ] 候補を選ぶと、入力欄には表示名(例: 「天草四郎」)だけが入る
- [ ] スマホ幅(360px)でも候補の行の表示が崩れない

## 成功指標

- 名前に入力文字を含まない候補について、なぜ表示されたかが画面上で分かる

## スコープ外

以下はこのフェーズでは実装しません:

- 別名で一致した候補の並べ替え(ラベルで一致した候補を先にするなど)。検索結果の順を保つ既存の仕様を変えない
- 日本語以外のラベルで一致した場合の表示(例: 「Oda Nobunaga」と入力して「織田信長」が出る場合)。`match.type` が `label` なので、これまでどおり表示する
- 候補を選んだ後の画面(タイムライン・結果)への別名の表示
