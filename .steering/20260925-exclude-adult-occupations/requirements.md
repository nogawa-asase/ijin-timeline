# 要求内容

## 概要

子供にふさわしくない職業(AV女優・ポルノ俳優など)がWikidataに登録されている人物を、候補から除外する。

## 背景

手動テストで「卑弥呼」と入力したところ、候補に「卑弥呼(1971年–) 日本のAV女優」だけが表示された。

- 歴史上の卑弥呼(Q234451)は、生年が「不明な値」のため仕様どおり候補から除外されている(生年不明の人物への対応は次の作業で検討する)
- 同じ名前で生年が登録されている人物だけが残った

PRDのセカンダリーペルソナは小学6年生とその保護者。教育目的のサービスで、成人向けの職業の人物が候補に表示されるのは避けたい。現状は、人物の内容で候補を絞る仕組みがない。

## 実装対象の機能

### 1. 職業による候補の除外
- Wikidataの職業(P106)に、教育上の観点からフィルタリングする職業が1つでも含まれる人物は、候補にしない(人間でない・生年がない場合と同じ扱い)
- 教育上の観点からフィルタリングする職業(2026-09-25時点でWikidataを確認):

  | ID | 職業 |
  |---|---|
  | Q1079215 | AV女優 |
  | Q8380347 | AV男優 |
  | Q488111 | ポルノ俳優 |
  | Q66382950 | ポルノ女優 |

- 通信回数・取得件数・表示件数(最大7件)は変えない。職業は、今の詳細取得(`props=claims`)の応答にすでに含まれている

### 2. 永続ドキュメントの更新
- 候補の条件に「教育上の観点からフィルタリングする職業の人物でない」ことを追記する

## 受け入れ条件

### 職業による候補の除外
- [ ] 職業に教育上の観点からフィルタリングする職業を含む人物は、`parsePerson` が `null` を返す
- [ ] 職業に教育上の観点からフィルタリングする職業を含まない人物、職業が登録されていない人物は、これまでどおりPersonに変換される
- [ ] 非推奨(deprecated)ランクの職業は判定に使わない
- [ ] 「卑弥呼」と入力すると、AV女優の人物が候補に出ない(候補が0件になり「該当する人物が見つかりませんでした」と表示される)
- [ ] 「織田」「豊臣」の候補は、これまでどおり表示される
- [ ] `node --test 'tests/**/*.test.js'` がすべて成功する

### 永続ドキュメントの更新
- [ ] PRD・機能設計書・用語集・手動テストチェックリストの候補の条件に、職業による除外が反映されている

## 成功指標

- 成人向けの職業が登録された人物が、候補一覧に表示されない

## スコープ外

以下はこのフェーズでは実装しません:

- 職業が登録されていない人物の除外(Wikidataのデータに依存するため、完全には防げない。限界としてドキュメントに明記する)
- 説明文(description)のキーワードによる除外(「AV」などの文字列判定は誤判定が多いため採用しない)
- 生年が不明な人物(歴史上の卑弥呼など)を候補に出すこと(次の作業で扱う)
- 除外した人物がいたことを画面に表示すること
